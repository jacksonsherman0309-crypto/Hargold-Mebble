# Imported World-Specific Packages

`IMPORT_FILES.bat` stores each import in a timestamped directory here.

The importer accepts:

- individual files;
- complete folders;
- ZIP packages, which are both preserved and expanded.

Original source structure and filenames are retained so world plans, course plans, enemy catalogs, encounter manifests, boss contracts, runtime modules, tests, editor files, and playable builds remain associated with their source package.

Codex must read `docs/world-specific-archive-policy.md` before using these files.

An imported package is not automatically current canon. Current canonical documents control conflicting names and campaign assignments, but reusable code and authored world/level mechanics should be adapted rather than discarded.

Some archived geometry files are coordinate-free construction scaffolds with pending positions. They are valuable authored plans but are not completed playable geometry.
