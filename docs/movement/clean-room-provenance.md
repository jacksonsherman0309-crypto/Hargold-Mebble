# Clean-room movement provenance

The production movement code in `src/gameplay/movement` was independently authored for Hargold & Mebble.

- No Nintendo source code, decompiled code, leaked material, binaries, constants, assets, animation data, or protected identifiers are included.
- External games are treated only as broad behavioral and craftsmanship references.
- Production names, module boundaries, state architecture, tests, and tuning values were designed independently for this repository.
- Numeric tuning is expressed at this project’s meter-scale collider and level scale. It is labeled provisional until production meshes, production collision, mobile hardware, and authored courses complete calibration.
- Archived Hargold & Mebble standalone files were inspected only to recover this project’s reusable concepts and integration requirements. Their obsolete numbers do not override current canon.
- Research notes are documentation, not executable production input. No copied source excerpt is embedded in the implementation.

Source categories used in `behavioral-reference.md` are limited to current canonical documents, the user-approved clean-room production target, observation of this project’s browser prototype, archived Hargold & Mebble project artifacts, and independently chosen project-design decisions.
