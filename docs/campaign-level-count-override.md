# Campaign Level-Count Override

Last updated: July 29, 2026

This file records the newest approved campaign-count rule and overrides older conflicting references in canonical documents, archived plans, manifests, and scaffolds.

## Locked rule

- Worlds 1–7 each contain **8 levels total**.
- The secret level is included within those 8 levels; it is not a ninth additional level.
- Therefore, Worlds 1–7 must not be described or implemented as “8 levels plus a secret level,” “9 completion slots,” or a separate `W-9` secret completion slot.
- Worlds 8–10 are unchanged by this directive until explicitly revised.

## Current campaign accounting

- Main-world completion slots: `7 × 8 = 56`.
- Worlds 8–10 retain 9 slots each for now: `3 × 9 = 27`.
- Current campaign total: **83 completion slots**.
- At 3 Compass Coins per level, the current campaign total is **249 Compass Coin slots**.

## Implementation requirement

Existing World 1–7 plans that currently use slots `W-1` through `W-9` require a deliberate authored remap. Do not silently delete, merge, or renumber the boss course, fork routes, or secret course. Until that remap is explicitly approved:

1. Treat the eight-total-level rule as authoritative.
2. Mark old ninth-slot references as legacy and non-authoritative.
3. Preserve authored level content without claiming the old nine-slot structure remains valid.
4. Require a focused slot-remap pass before finalizing progression data for Worlds 1–7.
