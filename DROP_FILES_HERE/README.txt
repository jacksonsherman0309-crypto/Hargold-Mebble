HARGOLD & MEBBLE — DROP COMPLETE OLD WORK HERE

Use this folder to give Codex the complete world-specific and level-specific archive.

1. Download the old Hargold & Mebble files from ChatGPT.
2. Drag individual files, complete folders, or ZIP packages into this folder.
3. Go back to the main Hargold-Mebble folder.
4. Double-click IMPORT_FILES.bat.
5. Return to Codex and say:

   Read AGENTS.md, docs/world-specific-archive-policy.md, and IMPORT_STATUS.txt. Inventory the complete imported package before changing code. Do not replace authored worlds and levels with a universal template.

The importer preserves original filenames and folder structure under:

archive/imported-packages/<import date and time>/

ZIP files are preserved and also expanded. Complete folders are copied recursively. Individual files are kept together in the same timestamped import.

The importer COPIES files. It does not delete the originals from this folder.
