HARGOLD & MEBBLE — DROP FILES HERE

This folder is the simplest way to give Codex older game files.

1. Download the old file or character-reference image from ChatGPT.
2. Drag it into this DROP_FILES_HERE folder.
3. Go back to the main Hargold-Mebble folder.
4. Double-click IMPORT_FILES.bat.
5. Return to Codex and say:

   Inspect the newly imported archive and reference files. Read AGENTS.md first.

The importer automatically sorts:

- full-motion HTML builds into archive/full-motion
- the level editor into archive/level-editor
- physics/specification files into archive/physics
- Hargold and Mebble reference images into assets/references
- Blender .blend files into assets/blender
- FBX, GLB and GLTF exports into assets/exports
- unknown files into archive/unclassified

The importer COPIES files, so the originals remain in this folder as a backup.
