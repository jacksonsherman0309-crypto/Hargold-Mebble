# Hargold & Mebble

Development and testing repository for the browser-playable Hargold & Mebble platformer prototype.

## Run locally

Open `index.html` directly in a modern browser, or serve the repository with any static web server.

## Current prototype

- Landscape-first browser test build
- Linear side-scrolling movement plane
- Keyboard and on-screen controls
- Basic movement, jumping, coins, hazards, checkpoint, and character swapping
- Placeholder canvas rendering until approved game assets are integrated

## Controls

- Move: `A` / `D` or arrow keys
- Jump: `Space`, `W`, or up arrow
- Swap hero: `Q`
- Restart: `R`

## Development rule

Gameplay code, test builds, level data, approved assets, and progress notes should be committed here so Codex and collaborators can test the actual project state.
